# 德州扑克筹码自动分配器

一个基于 WebSocket 的联机德州扑克筹码分配器，适用于朋友局线下玩牌时的筹码管理。

## 功能特性

- **实时筹码管理**：多人在线实时下注、跟注、加注、弃牌、All-in
- **庄家点选赢家**：每手结束后由庄家点选赢家名次，自动分配筹码
- **主池/边池计算**：自动处理 All-in 场景下的主池和边池，支持多人平分（奇数筹码按座位顺序分配）
- **场上玩家模块**：实时显示在场玩家、当前行动玩家、弃牌玩家自动移除
- **完整历史记录**：永久保存每手结算详情、买卖筹码、场外带入、转账等记录，支持表格化查看
- **牌局结算汇总**：重置牌局时生成结算汇总表，含净盈亏和转账金额（1注码=0.5元）
- **筹码操作**：玩家间买卖筹码、场外带入筹码、手动转账（处理庄家点错赢家、27奖励等场景）
- **撤销下注**：下错筹码可撤销重下（下一人已下注则不可撤销）
- **休息功能**：玩家可临时休息，休息中不参与本手，下一手恢复
- **房主任命庄家**：庄家掉线/休息导致对局卡住时，房主可手动任命新庄家
- **专业德州叫法**：场上玩家状态按标准叫法显示（open/limp/raise/3-bet/bet/call/check/all-in）
- **我的本手投入**：场上玩家模块头部实时显示本人本手累计投入
- **玩家管理一行化**：操作按钮精简为一行（换座/设房主/设庄/休息/移出），座位号弹窗修改
- **加时卡**：下注倒计时可申请加时
- **暗金商务界面**：深炭灰 + 哑光暗金配色，移动端友好

## 技术栈

- **后端**：Node.js + ws（WebSocket）
- **前端**：原生 HTML/CSS/JavaScript（单页应用）
- **数据存储**：JSON 文件（state.json + history.jsonl）

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动服务

```bash
# 默认端口 3000
npm start

# 指定端口
PORT=3017 npm start
```

### 环境变量

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `PORT` | `3000` | HTTP 服务端口 |
| `DATA_FILE` | `data/state.json` | 状态文件路径 |
| `HISTORY_FILE` | `data/history.jsonl` | 历史记录文件路径 |

### 访问

浏览器打开 `http://<服务器IP>:<端口>` 即可加入牌局。

## 使用说明

### 基本流程

1. 房主创建牌局，设置小盲/大盲/倒计时等配置
2. 玩家加入牌局，输入昵称和初始筹码
3. 庄家点击"开始一手"，自动发小盲/大盲
4. 玩家依次下注（跟注/加注/弃牌/All-in）
5. 四轮下注（翻前/翻牌/转牌/河牌）结束后，庄家点选赢家名次
6. 系统自动分配筹码，进入下一手

### 筹码操作

- **买卖筹码**：向其他玩家发起购买/出售请求，对方同意后完成
- **场外带入**：玩家自行增加筹码
- **手动转账**：直接向其他玩家转账（无需对方同意），用于处理庄家点错赢家、27奖励等场景

### 历史记录

- 牌局动态模块显示最近 300 条记录
- 点击"查看完整历史"查看所有记录（表格化展示）
- 每手结算详情：结算前筹码、本手投入、赢得、净盈亏、结算后筹码
- 牌局结算汇总：初始带入、买卖、场外带入、最终剩余、净盈亏、转账金额

## 配置说明

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 小盲 | 1 | 小盲注码 |
| 大盲 | 2 | 大盲注码 |
| 倒计时 | 60秒 | 每位玩家下注倒计时 |
| 加时卡 | 30秒×3次 | 加时卡时长和次数 |
